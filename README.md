# Green Portfolio — Betrand Juniko

A one-page portfolio built with plain HTML, CSS, and JavaScript. No framework installation is required.

## How to open it in VS Code

1. Extract the ZIP file.
2. Open the `green-portfolio` folder in VS Code using **File → Open Folder**.
3. Install the **Live Server** extension by Ritwick Dey.
4. Right-click `index.html`, then select **Open with Live Server**.

Alternatively, you can open `index.html` directly in your browser.

## Information you should replace

Find the following text in `index.html`:

- `your-email@gmail.com` → replace it with your active email address.
- `github.com/username` → replace it with your GitHub URL.
- `linkedin.com/in/username` → replace it with your LinkedIn URL.
- `instagram.com/username` → replace it with your Instagram URL.
- Update the About and Skills descriptions as needed.
- Update project statuses and details when the projects are completed.

## Changing the main color

Open `style.css`, then edit the color variables at the top of the file:

```css
:root {
  --green: #15945f;
  --green-bright: #24c77d;
  --green-dark: #073c29;
}
```

## Portfolio notes

The projects in this template are intentionally marked as **In development**, **Concept**, and **Planned**. Do not present them as completed projects until you have actually built them and uploaded the code or demo. Once a project is completed, replace the `Details coming soon` button with a link to its GitHub repository or live demo.
